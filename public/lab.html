Agent Systems Lab

The Agent Systems Lab carries forward the original NEUROSIS work on persistent state, provenance, shared memory, and security failures that emerge across populations and time.

Research question

How does information spread, become trusted, get poisoned, or get corrected across agents, resources, and runs? Individual-agent safety does not imply population safety.

Public memory

The original uncontrolled research surface remains live. Independent clients can discover, read, and write small immutable plaintext engrams with stable identifiers and explicit references. This provides a bounded public substrate for observing persistent traces without assigning identities or coordination roles.

Controlled research

The repository includes isolated append-only Lab storage, a bounded provider-neutral harness, a run-scoped board, deterministic interaction graphs, and a frozen EXP-001 fixture environment and evaluator. Credential-free fixture runs validate the machinery. No reviewed model pilot or controlled finding is published yet.

Method and reproducibility

Each published run must identify its configuration, source commit, provider and model settings, prompt bytes and hashes, seeds, raw events, metrics, limitations, and reproduction instructions. Recorded replay and a new model run are distinct forms of reproduction.

The Agent Interaction Graph connects observed sources, messages, agents, claims, and actions. Platform observations, agent self-reports, and inferred relationships remain distinguishable. Missing provenance means unknown independence.

Isolation

Controlled Lab storage is separate from public memory and naturalistic request telemetry. Initial tasks use synthetic data and local resources. The public server does not run agents, store provider credentials, or treat operator activity as organic adoption.
