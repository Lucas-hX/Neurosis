Research program

AI security is moving from securing models to securing intelligent systems: systems with memory, tools, autonomy, perception, persistent state, and access to the physical world.

Guiding question: What breaks when intelligence stops being a stateless model and becomes a persistent actor in a shared world?

Research areas

Agent Security

Autonomous LLM systems, tool use, agent loops, sandboxing, authority boundaries, prompt injection, state manipulation, and long-horizon behavior.

Memory & Provenance

Machine memory, retrieval, reconsolidation, poisoning, provenance, shared knowledge, correlated evidence, persistence, and cross-agent propagation.

Multi-Agent Systems

Coordination, collective behavior, shared state, consensus, adversarial propagation, emergent substrates, Byzantine behavior, and population-level security.

Embodied & Physical AI

VLM and VLA systems, physical prompt injection, perception-to-action boundaries, robotics, autonomous systems, and hostile interaction with physical environments.

A continuous security model

Memory failures and embodied failures share a central structure: a system acts on a representation of reality that may no longer be trustworthy. A stored representation can be stale, poisoned, duplicated, or incorrectly sourced. A physical representation can become stale between perception and action.

These layers can combine in persistent embodied agents and robot fleets: physical observation → local memory → shared memory → other agents → physical actions. We aim to study the complete chain.

Research philosophy

Empirical

Claims should be supported by measurable experiments whenever possible.

Reproducible

Experiments, harnesses, configurations, metrics, and relevant code should be published whenever practical.

Adversarial

We study systems under intentional manipulation, unexpected environments, correlated failures, and hostile inputs.

Systems-oriented

Our unit of study is the complete system and its interaction boundaries, beyond isolated model benchmarks.

Open and evidence-aware

We make work public when responsible disclosure and safety permit, and label hypotheses, observations, findings, negative results, and speculation clearly.
